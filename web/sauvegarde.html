Sauvegarde locale

Votre dossier, chiffré avant de quitter l’appareil.

La sauvegarde contient le suivi quotidien et le calculateur. Le code de récupération ne reste pas dans REBOOT : sans lui, personne ne peut lire le fichier — pas même l’application.

Créer une sauvegarde

Conservez le fichier et son code de récupération dans deux endroits distincts.

Vous pouvez saisir votre propre phrase, ou générer un code aléatoire.

Restaurer une sauvegarde

Le fichier est d’abord vérifié et déchiffré. Aucune donnée n’est remplacée avant votre confirmation.
